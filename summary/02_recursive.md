# 재귀

수학적 귀납법을 알고리즘에 적용한다.

    1. 문제를 읽고, '특정 틀을 반복하면 답이 도출되겠다'는 생각을 떠올린다.
    (예를 들어, n + 1 번째는 n 번째 또는 그 이전 결과를 사용하면 되겠다?)
    
    2. base condition 정의하여 재귀 탈출 명시
    
    3. 세운 로직이 적합한지 머릿속으로 흐름을 그리면서 다시 생각하기

보통 동일한 로직을 반으로 쪼개서 생각한다던가, 사분면같은 4분할 등이 실마리가 되는 경우가 많음

재귀적인 연산이 쌓여서 오버플로가 발생할 수 있음을 항상 생각한다. 입력으로 int 값을 받지만 결과를 담는 자료형을 long으로 잡아야 할 때가 많다.
